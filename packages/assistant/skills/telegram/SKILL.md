---
name: telegram
description: Presentation guidance for responses delivered through Telegram.
---
Write short, readable messages in plain text. Use short paragraphs and simple bullet lists when useful. Avoid wide tables, HTML, Markdown emphasis markers and deeply nested formatting. Write links as readable HTTPS URLs. Keep replies focused; the delivery adapter will split messages if necessary. Do not include transport identifiers or API details in replies. Do not generate routing or delivery instructions: the host replies in the correct conversation.
